AI Agent Skill

为 AI Agent 提供专用图片处理 Skill

将 imgcli 的全部 11 个命令封装为 Agent Skill，安装后 Agent 自动识别图片处理意图并调用正确的命令。无需手写 Function Calling 定义，一条指令即可安装。

Skill 文件结构
imgcli/
├── SKILL.md # 技能定义 & 触发规则
└── references/
└── commands.md # 完整命令参数文档

---
name: imgcli

  enhance, LabelMe mask generation, data
  augmentation, grid crop, OCR (PaddleOCR

  and segmentation (SAM3). TRIGGER when:
  user asks to convert, resize, crop, enhance,
  augment, erase, upscale, or process
  images via CLI..."

Core Features

11 大核心能力

格式转换

JPG / PNG / BMP 格式互转，支持单文件与批量处理

缩放

Lanczos3 重采样算法，精准缩放到指定分辨率

增强

调整对比度、亮度，Unsharp Mask 锐化，感知亮度检测

标注掩码

从 LabelMe JSON 标注生成二值掩码图片

数据增强

翻转、旋转、色彩抖动、仿射变换，批量扩充训练集

裁剪

网格切片裁剪，自动步长计算，支持重叠覆盖

OCR 文字识别

PaddleOCR V5 驱动，支持 JSON 结构化输出

AI 去背景

BEN2 模型驱动，支持 CPU / CUDA / CoreML 推理

对象擦除

MIGAN 模型驱动，掩码指定区域，AI 自动修复背景

AI 超分辨率

Real-ESRGAN 驱动，2x/4x 放大，分块推理适配显存

图像分割

SAM3 模型驱动，文本/框提示，自动导出 LabelMe 标注

CLI Examples

命令行示例

convert — 格式转换
$ imgcli convert photo.png -f jpg
→ convert_output/photo.jpg ✓
resize — 缩放
$ imgcli resize photo.jpg -W 800 -H 600
→ resize_output/photo.jpg (800×600) ✓
enhance — 增强
$ imgcli enhance photo.jpg --contrast 1.5 --sharpen
→ enhance_output/photo.jpg ✓
mask — 标注掩码
$ imgcli mask annotation.json --label cat
→ mask_output/annotation.png ✓
augment — 数据增强
$ imgcli augment photo.jpg -a hflip vflip -n 3
→ augment_output/ (6 images) ✓
crop — 裁剪
$ imgcli crop photo.jpg -W 512 -H 512
→ crop_output/ (9 tiles) ✓
ocr — 文字识别
$ imgcli ocr screenshot.png -f json
→ [{"text": "Hello", "conf": 0.97}, ...] ✓
rmbg — AI 去背景
$ imgcli rmbg photo.jpg
→ rmbg_output/photo.png (RGBA) ✓
seg — 图像分割
$ imgcli seg photo.jpg -t "person" --labelme
→ seg_output/photo_mask.png + .json ✓
erase — 对象擦除
$ imgcli erase photo.jpg --mask mask.png
→ erase_output/photo_erase.png ✓
upscale — AI 超分辨率
$ imgcli upscale photo.jpg -m RealESR_Gx4
→ upscale_output/photo_4x.png ✓
Quick Start

快速开始

1 安装
# 前置条件：Rust 工具链 + C++ 编译器
$ git clone https://github.com/go-restream/imgcli.git
$ cd imgcli
$ cargo install --path .

支持 macOS · Linux · Windows

2 使用
$ imgcli rmbg photo.jpg
✓ rmbg_output/photo.png

$ imgcli convert ./images/ -f png
✓ convert_output/ (24 files)

单文件或批量处理

3 AI 模型
# ocr / rmbg / erase / upscale / seg 需额外模型
# 下载到 ~/.imgcli/models/

$ imgcli erase photo.jpg --mask mask.png
✓ MIGAN model loaded

支持 auto / cpu / cuda / coreml
